# Kickbase Kader-Analyzer ⚽️📈

Ein smartes Web-Dashboard zur Analyse deines Kickbase-Kaders. Behalte deinen Kontostand im Blick, simuliere Spielerverkäufe und berechne automatisch deine zu erwartenden Boni (Trading- & Spieltagsboni).

## 🚀 One-Click Deployment (Für Liga-Kollegen)

Damit deine Login-Daten komplett privat bleiben und nicht über fremde Server fließen, hostet sich hier jeder sein Dashboard einfach selbst. Das dauert keine 2 Minuten, ist **100 % kostenlos** und erfordert keinerlei Programmierkenntnisse.

Klicke einfach auf den folgenden Button, um dir deine eigene private Instanz bei Vercel zu erstellen:

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https://github.com/osn1337/KBAnalyzer)

### 🛠 Wie funktioniert das? (Schritt-für-Schritt)
1. Klicke auf den blauen Deploy-Button oben.
2. Logge dich bei Vercel ein (am einfachsten direkt mit einem GitHub- oder Google-Account).
3. Vercel fragt dich, ob ein privates Repository für dich erstellt werden soll. Bestätige das.
4. Klicke auf **Deploy**.
5. Nach ca. 15 bis 30 Sekunden ist deine App fertig. Du erhältst direkt einen Link zu deinem persönlichen Kader-Analyzer!

💡 **Tipp:** Öffne den Link auf deinem Smartphone (Safari oder Chrome) und füge die Seite über die Browser-Optionen **"Zum Home-Bildschirm"** hinzu. So verhält sich das Dashboard wie eine ganz normale App.

## 🔒 Datenschutz & Sicherheit
Dieses Tool läuft dezentral. Wenn du die App über den Button oben deployt hast, läuft sie **ausschließlich für dich**. 
- Deine Kickbase-E-Mail und dein Passwort werden **nicht** gespeichert.
- Die Daten werden lediglich in dem Moment deines Logins über deinen eigenen, neu erstellten Vercel-Proxy direkt an die offiziellen Kickbase-Server geschickt, um deinen Kader abzurufen.
